# CUTLINE Milestones 1–2 (Foundations + App Shell) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a CUTLINE desktop app that builds on Windows, macOS and Linux. It opens a professional, themed shell with
resizable panels and workspaces, creates/opens/saves real `.cutline` projects, edits sequence and track settings with
full undo/redo, and routes every keyboard shortcut through a context-aware, customisable system.

**Architecture:** `cutline_core` holds the model, commands, undo and project I/O, and depends on Qt Core only.
`cutline_media` wraps FFmpeg (only build-info for now). `cutline_ui` is a static library plus QML module (`Cutline`)
holding view models, ActionRegistry, ShortcutRouter, workspaces, theme and icons. The `cutline` executable is a thin
`main.cpp`. Every change to a project goes through a core `Command`, and every key press through the ShortcutRouter.

**Tech Stack:** C++20, CMake ≥ 3.28 + Ninja, Qt 6 (≥ 6.8: Core, Gui, Quick, QuickControls2, Svg, Test),
FFmpeg (LGPL, via vcpkg on Windows/macOS, distro packages on Linux), Qt Test + CTest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-18-cutline-design.md`. Read §3, §4, §6–§8, §13, §14 and §16 before starting.
Visual reference: `docs/reference-analysis.md`.

## Global Constraints

- License: CUTLINE code is MIT. No GPL dependency may enter an official build (`CUTLINE_OFFICIAL_BUILD=ON`).
- C++20. Qt ≥ 6.8 (`qt_standard_project_setup(REQUIRES 6.8)`). CMake ≥ 3.28. Generator: Ninja.
- Warnings: MSVC `/W4 /permissive- /utf-8 /Zc:__cplusplus`; GCC/Clang `-Wall -Wextra -Wpedantic`. `CUTLINE_WERROR=ON` in CI.
- `src/core` links `Qt6::Core` only; it must never include Gui, Quick or FFmpeg headers.
- Every project mutation goes through `cutline::Command` executed by `cutline::Document`.
- An action is registered in `ActionRegistry` only when its handler works. No menu item, button or shortcut may
  exist without a registered, implemented action.
- All user-visible strings use `tr()` / `qsTr()`. English only.
- Neutral (R = G = B) surface colours. One accent, red (the user's choice after the Task 6 mockup): dark `#E5484D`,
  light `#C62F35`. Red never carries meaning on its own: errors always have the warning icon and text.
- Presets order (user): YouTube 16:9 first, then vertical 9:16 (1080×1920) for Shorts/TikTok/Reels.
- Fonts: Inter (UI), JetBrains Mono (timecode). Both OFL-1.1 and bundled.
- No network access anywhere in the app. No telemetry.
- The default layout must work at 1366×768.
- Exact error and title copy given in this plan is final; tests assert it.
- Window title format: `<project name> — CUTLINE`, with `*` after the name when there are unsaved changes.
- Every task ends with a commit on the milestone branch. Nothing is pushed without the user's go-ahead.

## Review Focus

1. **Non-ASCII and space-containing paths** (`…\Zoë Vidéos\Mon projet 東京.cutline`): save, open, recent list and
   window title must all work. Pinned in Task 9 (`unicodePathRoundTrip`) and Task 13 (`recentProjectsUnicode`).
2. **Saving to a read-only file or missing folder**: an error dialog, the project stays dirty, and the existing file
   is unchanged. Pinned in Task 9 (`saveFailureLeavesExistingFileIntact`) and Task 13 (`saveErrorKeepsDirty`).
3. **Non-US keyboards**: Shift+digit on US (gives `!`) and AZERTY (digits need Shift), Ctrl+Shift+Tab (arrives as
   Backtab), numpad keys. Pinned in Task 11 (`shiftDigitRowUs`, `shiftDigitAzerty`, `backtabNormalized`,
   `keypadStripped`).
4. **Small screen + large UI scale** (1366×768 at 150%): no panel shrinks below its minimum and the header doesn't
   overflow. Pinned in Task 14 (`smallScreenLayoutFits`).
5. **Corrupt settings files** (broken workspace JSON, broken shortcut profile): the app falls back to defaults, warns
   once in the status bar, and never crashes. Pinned in Task 10 (`corruptStoredProfileFallsBack`) and Task 12
   (`corruptStoredWorkspaceFallsBack`).

- [ ] **Step 5: Implement `Time.cpp`**
  - **Rational maths without overflow** (MSVC has no `__int128`). For frames→ticks, let `K = kTicksPerSecond * den`,
    `q = frames / num` and `r = frames % num`; then `ticks = q*K + round((r*K) / num)`. For ticks→frames, let
    `q = ticks / K` and `r = ticks % K`; then `frames = q*num + (r*num) / K`. Both use floor semantics for negative
    input.
  - **Drop-frame:** use the standard SMPTE algorithm with nominal 30 or 60, dropping 2 or 4 frames per minute
    except every tenth minute. The separator before the frames field is `;` in Drop mode and `:` otherwise.
  - **`startHour`** adds whole hours before formatting and is subtracted after parsing.

**Routing rules for `KeyPress` and `ShortcutOverride` on the attached window, in order:**
1. If an operation is active, Escape calls its cancel function and is consumed. Other keys pass through.
2. If the focus item is a recorder, pass through.
3. If a modal is open, Escape calls `close()` on the top modal and is consumed. Other keys pass through to the modal.
4. If focus is text entry, Escape moves focus to the nearest panel's root (`forceActiveFocus`) and is consumed. Only
   actions with `worksInTextEntry` match. Everything else passes through to the field.
5. Otherwise, try each candidate in `registry.matching(candidate, panelContext(focus), textEntry)`. The first match
   is triggered and the event consumed, even when the action is disabled.

**`candidates()` normalisation:**
- `KeypadModifier` is stripped.
- `Key_Backtab` becomes `Key_Tab` plus Shift.
- **Digit row:** when Shift is held and the key's native code is on the digit row, the candidate `Shift+<digit>` is
  added first. On Windows that means scan codes 0x02–0x0B for 1–0; on macOS virtual keys `kVK_ANSI_0`…`kVK_ANSI_9`;
  on Linux X11/xkb, keycodes 10–19 (evdev + 8).
- **Shifted symbols:** for a printable non-letter, non-digit key with Shift as the only modifier, the candidate
  without Shift is also added. That way `Shift++` also matches `+`.
